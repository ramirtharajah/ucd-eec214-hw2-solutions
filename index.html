# shunt regulator is an open circuit load, in which case all the

# increases. Plot efficiency as a function of load resistance
# starting at minimum acceptable load and ending at 100 times the

# are in parallel the diode current is the difference between the input

ZENER DIODE REGULATOR¶

$$KCL: I_{IN} = I_D + I_L = \frac{V_{IN} - V_{OUT}}{R_S}$$$$I_D = \frac{V_{OUT} - V_Z}{R_Z} \le \frac{P_{max}}{V_Z} \quad \text{neglecting } R_Z$$$$I_L = \frac{V_{OUT}}{R_L} = \frac{V_Z + I_D R_Z}{R_L}$$

Max power incl. $R_Z$:

$$P_{max} \ge I_{D,max} V_Z + I_{D,max}^2 R_Z$$$$I_{D,max}^2 R_Z + I_{D,max} V_Z - P_{max} \le 0$$$$I_{D,max} = \frac{-V_Z \pm \sqrt{V_Z^2 + 4 R_Z P_{max}}}{2 R_Z}$$

(1)

$$\frac{V_{IN} - V_{OUT}}{R_S} = \frac{V_{OUT} - V_Z}{R_Z} + \frac{V_{OUT}}{R_L} \Rightarrow \frac{V_{IN}}{R_S} + \frac{V_Z}{R_Z} = V_{OUT} \left(\frac{1}{R_S} + \frac{1}{R_Z} + \frac{1}{R_L}\right)$$$$V_{OUT} = \left(\frac{V_{IN}}{R_S} + \frac{V_Z}{R_Z}\right) \frac{1}{\frac{1}{R_S} + \frac{1}{R_Z} + \frac{1}{R_L}} = \left(\frac{V_{IN}}{R_S} + \frac{V_Z}{R_Z}\right) (R_S \vert{}\vert{} R_Z \vert{}\vert{} R_L)$$

Solving for equation (1) for $R_L$.

$$\frac{V_{OUT}}{R_L} = \frac{V_{IN} - V_{OUT}}{R_S} + \frac{V_Z - V_{OUT}}{R_Z} \Rightarrow R_L = \frac{V_{OUT}}{\frac{V_{IN} - V_{OUT}}{R_S} + \frac{V_Z - V_{OUT}}{R_Z}}$$

Solving for $R_L$ in terms of $V_{IN}$, $R_S$, $R_Z$

$$\frac{V_{IN} - (V_Z + I_D R_Z)}{R_S} = \frac{V_Z + I_D R_Z}{R_L} + I_D \Rightarrow \frac{V_Z + I_D R_Z}{R_L} = \frac{V_{IN} - (V_Z + I_D R_Z)}{R_S} - I_D$$$$R_L = \frac{V_Z + I_D R_Z}{\frac{V_{IN} - (V_Z + I_D R_Z)}{R_S} - I_D}$$

Another expression for Vout:
